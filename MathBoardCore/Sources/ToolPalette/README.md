# ToolPalette

## Purpose
UI-only drawing tool palette module with compact, collapsible, and radial interaction variants.

## Responsibilities
- Define tool/palette models and definitions.
- Provide palette layout and theming behavior.
- Render compact, collapsible, radial, and prototype palette views.

## Key Files
- `ToolPaletteDefinitions.swift` / `ToolPaletteModels.swift`
- `ToolPaletteLayout.swift` / `ToolPaletteTheme.swift`
- `CompactToolPaletteView.swift` / `CollapsibleToolPaletteView.swift` / `RadialToolPaletteView.swift`

## Dependencies
- Internal module dependencies: none.
- External package dependencies: none.

## Integration Status
- Dependency-free module integrated by `Presentation`.
