# SlideNav

## Purpose
Isolated slide-navigator redesign sandbox for iterating on navigation UI/UX before production porting.

## Responsibilities
- Define mock slide navigation models and state transitions.
- Render alternate navigator shell, filmstrip, and placement behaviors.
- Provide preview harnesses for design iteration and validation.

## Key Files
- `SlideNavModels.swift`
- `SlideNavView.swift`
- `SlideNavMockArt.swift`
- `SlideNavPreviewHarness.swift`

## Dependencies
- Internal module dependencies: none.
- External package dependencies: none.

## Integration Status
- Standalone prototype target and scheme.
- Design/port notes: `SlideNav_status.md`.
